# Вопросы анкеты

Сиды задаются в `backend/db.go` при пустой таблице `questions`.

1. Как вас зовут? — `text`
2. Какой ваш любимый язык программирования? — `radio`: Go, Python, JavaScript, Java, Другой
3. Какой у вас опыт в разработке? — `select`: Менее 1 года, 1–3 года, 3–5 лет, Более 5 лет
4. Что вы хотите изучить в этом курсе? — `text`
5. Откуда вы узнали о курсе? — `radio`: Друзья / коллеги, Соцсети, Поисковик, Реклама

Актуальный список всегда лучше брать tool-ом `get_questions` (живой `GET /questions`),
а не из этого файла: сиды применяются только при первой инициализации БД.
