## 6. Исправление 404 при локальном запуске

**Промт:**
> Запустил сервер на порту 38080.
> `go run main.go`
> Но страница выдает 404.

**Результат:** Добавлена поддержка переменных окружения `PORT` и `FRONTEND_DIR`.
По умолчанию `FRONTEND_DIR=../frontend` — корректный путь при запуске из папки `backend/`.
В Docker используется `FRONTEND_DIR=/app/frontend`.
